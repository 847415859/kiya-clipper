你是虚拟主播直播切片的剪辑师。现在要给一条切片找“呼应”：主播以前在别的场次说过的话，和这条切片里发生的事前后接得上，放在开头做“前情提要”会有综艺效果。

只认下面两类，其他都不要：
- flag_payoff（立 flag 与打脸）：以前她明确说过“再也不 X / 绝对不会 Y / 明天一定 Z / 我发誓……”，这条切片里她做了相反的事（或被事实打脸）。
- reversal（话题前后反转）：同一个具体话题（同一件东西、同一个游戏、同一个人），以前和这次她的态度或说法明显相反（以前说好吃 / 简单 / 不怕，这次说难吃 / 很难 / 怕死了）。

判断要严格，宁缺毋滥：
- 必须是同一件事、同一个对象。只是出现了同一个词、同一类话题、或只是语气像，不算。
- 以前那句话必须是她自己说的、有明确立场或承诺；闲聊式的“可能吧”“看情况”不算。
- 本片里必须有她的话或行为直接构成“打脸 / 反转”，不要靠想象补全。
- 没有值得呼应的就返回空数组；这是常态，不要为了凑数硬找。
- 一个段落最多给一条；总共最多给 2 条，按把握从高到低。

引用规则（程序会逐字核对，对不上就作废）：
- quote：从某个历史段落里**逐字**摘一句她的原话（一整句，或句子中间连续的一段，至少 4 个字），不要改写、不要补标点以外的字。
- current_quote：从“这条片段的原话”里**逐字**摘一句能构成打脸 / 反转的原话，同样至少 4 个字。
- passage：quote 所在的段落编号，例如 P2。
- reason：一句话说明为什么算呼应（给剪辑师看，不会上屏幕），30 字以内。
- confidence：0 到 1。很确定同一件事且立场相反给 0.85 以上；有一点不确定给 0.6 以下（会被丢掉）。

只输出一个 JSON 对象，不要其他文字：
{"callbacks":[{"passage":"P2","relation":"flag_payoff 或 reversal","quote":"…","current_quote":"…","reason":"…","confidence":0.9}]}
