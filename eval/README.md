# 评测集

评测集是“什么是好切片”的标准答案。之后每次改权重、词典、提示词、模型，都在它上面跑分，用数据判断是否真的变好了。

## 文件

| 文件 | 内容 |
| --- | --- |
| `annotations.csv` | 人工标注的有趣片段（标准答案）。从 `annotations_template.csv` 复制后填写 |
| `reviews/` | 阶段 0 手工验证时填好的 `peaks.csv`，每场一个，文件名用场次名，如 `20261109-2000.csv` |
| `results.csv` | 每次实验的结果记录 |

## annotations.csv 怎么填

每个有趣片段一行：

| 列 | 说明 | 例子 |
| --- | --- | --- |
| session | 场次名，与分析输出目录名一致 | 20261109-2000 |
| start | 片段开始，相对开播的时分秒 | 01:23:40 |
| end | 片段结束 | 01:24:30 |
| type | 破防 / 口胡 / 互动 / 金句 / 高能 / 其他 | 破防 |
| source | 标注来源：fans（粉丝时间轴）/ clip（已有切片号）/ self（自己看）/ streamer（主播标记） | fans |
| quality | 1–3，3 = 必切的名场面 | 3 |
| note | 发生了什么 | 恐怖游戏被开门杀吓到尖叫 |

**标注来源**：

1. 去 kiya 的录播、切片视频评论区，找粉丝整理的“高能时间轴”。
2. 已有切片号的高播放视频，在简介或画面里找原场次时间，回溯到开播后的时分秒。
3. 自己看录像时遇到的有趣片段。

目标：阶段 1 结束前至少 5 场、每场 10 条以上。

## 命中怎么算

一个候选片段和任一标注片段**时间有重叠**，就算命中。

- **Top 10 命中率** = 前 10 个候选里命中的个数 ÷ 10
- **召回率** = 被候选命中的标注片段数 ÷ 标注片段总数

阶段 1 会加一个 `evaluate.py` 自动计算这两个数；阶段 0 先在 `peaks.csv` 里手工数 Y 的比例。

## results.csv 怎么记

每改一次就加一行：日期、改了什么、版本、场次数、Top10 命中率、召回率、备注。
