# 剪辑师工作流优化

本轮重点减少找原话、调整起止、校对字幕和误操作返工。入口为“成片编辑”，延续已有的观众体验检查。

## 原话定位与试听

编辑器在时间轴下显示素材前后各 15 秒的原话，可搜索原文和修订文字。时间标记使用整场时间，点击后换算到当前素材位置。

- “试听”从句首播放，达到句末暂停。
- “从此句开始”“到此句结束”调整成片起止，至少保留一秒。
- 跨素材边界的句子只允许试听素材内部分，不能直接用不完整句子设置边界。点“扩入素材”后，按提示保存并生成新预览。
- 素材范围变化后会重新查询原话，旧请求返回的结果不会覆盖新范围；旧视频与范围不一致时禁用逐句定位和试听。
- 接口按当前主播隔离；单次查询最多 530 秒、返回最多 1000 句，前端先显示搜索结果中的前 120 句。

## 当前切片字幕修订

点一句旁的“改字幕”，直接编辑文字，改动随顶部“保存”写入剪辑脚本的 `subtitles.sentence_overrides`，不是全局纠错词。

- 每条修订同时保存整场 `t0/t1`、原文 `original` 与修订 `text`，防止同一句原话在别的时间也被误改。
- 原声、整场转写、其他切片不变。旧审核片段或素材预览烧好的字幕不会因保存而变化，须重新渲染成片检查。
- 修订句不沿用已经失效的原逐词时间：按原句范围重新分条，在成片中按句展示，不做旧逐词高亮。字幕样式的分条和标点处理仍生效。
- 人工逐句修订优先于全局纠错词。若重新转写导致原文或时间变化，保存、渲染和质检会提醒未匹配的修订，不强行套用。
- 修订内容不能留空；可以“恢复原文”移除这一句的修订。当前查询范围外的旧修订仍保留，界面会标明尚未匹配。

## 撤销、重做和快捷键

编辑页保留最多 60 个本地快照，包含起止、素材范围、效果、字幕修订、字幕样式、音乐和前情呼应。连续 300ms 内的编辑合并记录；保存后仍可撤销，撤回到已保存版本时不再显示“未保存”。

| 操作 | 快捷键 |
| --- | --- |
| 保存 | Ctrl / Cmd + S |
| 撤销 | Ctrl / Cmd + Z |
| 重做 | Ctrl / Cmd + Shift + Z |
| 当前播放位置设为成片起点 / 终点 | I / O |
| 前后移动五秒 | J / L |
| 按 30fps 时间步进 | 左 / 右方向键 |
| 播放或暂停 | 空格 |

文本输入框保留原生编辑与撤销，不会触发剪辑的 I/O、删除或跳转。弹窗也不响应剪辑快捷键。

历史只保留在当前编辑页内；重新加载、切换片段或选择 AI 版本会重新建立历史，离开前仍需保存。保存校验期间继续输入的改动不会被旧响应覆盖，会保留为“未保存”；再次保存后再渲染。

## AI 原稿对照

右侧显示选定 AI 版本与当前编辑的整场起止、效果新增 / 删除 / 逐字段修改，以及音乐、呼应和字幕开关的变化。效果优先按稳定 ID 匹配，旧脚本兼容按类型与近邻时间匹配；对比使用整场时间，扩展素材范围不会被误认为所有效果都移位。

对照面板只读，可以定位当前效果，不替换脚本。原有“还原 AI 原稿”仍需确认；原稿缺失时可继续手工编辑。

## 验证边界

使用模拟接口和测试视频验证页面操作；使用实际 FFmpeg 与假 Remotion 渲染器验证字幕修订进入渲染 props、原声时间不变和旧脚本兼容。没有进行真实场次、真实模型或线上发布测试，也未部署服务器。
