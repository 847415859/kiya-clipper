# 剪辑师工作流优化

本轮重点减少找原话、调整起止、校对字幕和误操作返工。入口为“成片编辑”，延续已有的观众体验检查。

## 原话定位与试听

编辑器在时间轴下显示素材前后各 15 秒的原话，可搜索原文和修订文字。时间标记使用整场时间，点击后换算到当前素材位置。

- “试听”从句首播放，达到句末暂停。
- “从此句开始”“到此句结束”调整成片起止，至少保留一秒。
- 跨素材边界的句子只允许试听素材内部分，不能直接用不完整句子设置边界。点“扩入素材”后，按提示保存并生成新预览。
- 素材范围变化后会重新查询原话，旧请求返回的结果不会覆盖新范围；旧视频与范围不一致时禁用逐句定位和试听。
- 接口按当前主播隔离；单次查询最多 530 秒、返回最多 1000 句，前端先显示搜索结果中的前 120 句。

## 当前切片字幕修订

点一句旁的“改字幕”，直接编辑文字，改动随顶部“保存”写入剪辑脚本的 `subtitles.sentence_overrides`，不是全局纠错词。

- 每条修订同时保存整场 `t0/t1`、原文 `original` 与修订 `text`，防止同一句原话在别的时间也被误改。
- 原声、整场转写、其他切片不变。编辑器生成干净素材后以独立字幕层显示修订；旧审核片段烧好的字幕不会因保存变化，最终仍需渲染验收。
- 修订句不沿用已经失效的原逐词时间：按原句范围重新分条，在成片中按句展示，不做旧逐词高亮。字幕样式的分条和标点处理仍生效。
- 人工逐句修订优先于全局纠错词。若重新转写导致原文或时间变化，保存、渲染和质检会提醒未匹配的修订，不强行套用。
- 修订内容不能留空；可以“恢复原文”移除这一句的修订。当前查询范围外的旧修订仍保留，界面会标明尚未匹配。

## 撤销、重做和快捷键

编辑页保留最多 60 个本地快照，包含起止、素材范围、效果、字幕修订、字幕样式、音乐和前情呼应。连续 300ms 内的编辑合并记录；保存后仍可撤销，撤回到已保存版本时不再显示“未保存”。

| 操作 | 快捷键 |
| --- | --- |
| 保存 | Ctrl / Cmd + S |
| 撤销 | Ctrl / Cmd + Z |
| 重做 | Ctrl / Cmd + Shift + Z |
| 当前播放位置设为成片起点 / 终点 | I / O |
| 前后移动五秒 | J / L |
| 按 30fps 时间步进 | 左 / 右方向键 |
| 播放或暂停 | 空格 |

文本输入框保留原生编辑与撤销，不会触发剪辑的 I/O、删除或跳转。弹窗也不响应剪辑快捷键。

撤销栈只保留在当前编辑页内；重新加载、切换片段或选择 AI 版本会重新建立撤销栈。自动草稿和正式保存历史在服务器另存，见下文。保存校验期间继续输入的改动不会被旧响应覆盖，会保留为“未保存”；再次保存后再渲染。

## AI 原稿对照

右侧显示选定 AI 版本与当前编辑的整场起止、效果新增 / 删除 / 逐字段修改，以及音乐、呼应和字幕开关的变化。效果优先按稳定 ID 匹配，旧脚本兼容按类型与近邻时间匹配；对比使用整场时间，扩展素材范围不会被误认为所有效果都移位。

对照面板只读，可以定位当前效果，不替换脚本。原有“还原 AI 原稿”仍需确认；原稿缺失时可继续手工编辑。

## 验证边界

使用模拟接口和测试视频验证页面操作；使用实际 FFmpeg 与假 Remotion 渲染器验证字幕修订进入渲染 props、原声时间不变和旧脚本兼容。没有进行真实场次、真实模型或线上发布测试，也未部署服务器。


## 干净预览与片中删除

编辑器优先生成不烧录字幕的 480p 素材，旧审核片段仍可查看，并明确标识其字幕尚未更新。当前字幕分条、逐句修订、关键词及删除后的时间由 worker 计算；字幕 DOM 样式树与 Remotion 共用，放大运镜不再放大字幕。素材分段缺失时不生成会导致时间错位的干净预览。

“片中删除”输入相对素材的起止秒数，也可从播放位置取值。删除区间与自动营业话区间取并集；重叠只计一次，可关闭自动删除营业话。调整素材范围会平移并裁去范围外的删除段。播放跳过删除段，暂停时仍可定位接缝检查。保存、撤销及 AI 原稿对照均保留这些设置。

渲染、预览、质检共用删除时间计算。删除后的字幕和效果移到同一时间轴；完全删除的效果不再出现。跨接缝字幕保留剩余词，人工校对字幕保留整句并标记供复查。视频缓存按具体起止与删除区间散列，删除总时长相同也不会串用。

背景音乐预听使用与成片一致的起点、修剪后循环范围、说话压低、淡入与淡出；暂停画面会暂停音乐。短曲循环的音量曲线沿完整主片延续，避免压低位置每次循环重新开始。实际音频、字体差异和前情呼应仍以试渲染为准。

## 局部试渲染

顶部“局部试渲染 10 秒”从当前成片位置前约 2 秒开始，最多取 10 秒；接口与 CLI 支持最多 30 秒。范围按最终成片时间计算，包含前情呼应。Remotion 对完整组合指定帧范围，保留原动画、字幕和音频相位；首次仍需准备完整干净源视频，后续复用缓存。

结果单独存放于 `render_previews/`，不会进入发布成片列表，也不覆盖正式成片、正式渲染 props 或质检。右侧可播放历次结果。编辑保存不会更新已有试渲染，调整后需重新生成；旧录像缺失导致前情回退文字卡时，以实际渲染结果为准。

```bash
.venv/bin/python scripts/render.py output/<场次>/candidates.json --rank 1 --height 480 --range-start 4 --range-end 14
```

## 自动草稿、保存历史和版本冲突

修改停顿约 1.2 秒后自动保存独立服务器草稿，界面显示等待、成功或失败状态；未完成自动保存时仍可能丢失最新输入，离开前请检查状态。草稿允许保存暂时未通过正式校验的输入，不直接成为渲染脚本。多个页面使用不同草稿 ID，同一页面旧请求不会覆盖更新的草稿。

“草稿与历史版本”可查看最近 30 条恢复记录，点击载入后可撤销，检查后再正式保存。切换恢复记录或载入服务器最新版本前，会保留当前未保存草稿；保存失败则保留当前页面。正式保存按内容散列归档版本；旧版本保存遇到其他页面已更新时返回 409，不覆盖服务器。先载入最新版本，再从草稿恢复需保留的改动并复查。

数据按主播、场次和切片隔离，位于 `edits/drafts/<序号>/` 与 `edits/history/<序号>/`；不会自动清理历史文件。恢复记录不是录像备份，服务器文件仍需正常备份。


## Seedream 自定义补充与封面版本选择

入口：成片编辑页右侧的发布卡片。

1. 在“封面字”填需要显示的文案；留空时 Seedream 成品不叠加大字。
2. 在“生图补充”填写构图、色彩、道具或风格要求，最多 1500 字。这些内容追加到自动主题与视觉方案中，不需要重写整份提示词。想显示在图片上的文字请填“封面字”，避免把排字要求混进底图要求。
3. “直播画面”适合重新设计；“所选 / 上次生图底图”适合延续已完成的设计。先选择历史封面，再选该底图，可以从旧版本继续完善。旧版没有独立底图时会使用该版本成品作参考，不会误用其他版本的底图。
4. “预览生图提示词”显示自动方案与补充要求合并后的内容，不截图、不调用 Seedream、不写发布包。确认后点击“Seedream 生图”才发起生成。
5. 生成完成后由程序叠字，保存无字底图和成品。每次成功生成都新增一个独立版本，显示在“已生成版本”中；点击即可设为发布封面，不重新生成。当前版本以边框和“使用中”标识。

封面字、补充要求、参考选择可随“保存文字与生图设置”保存，成功生图也会记住本次提交的要求。保存设置不生成图片；生成期间继续输入的补充与简介会留在页面，不被旧响应覆盖，但这些后续输入仍需再次保存。未点击生成或保存的发布表单输入不属于剪辑脚本自动草稿。

历史成品和底图分别保存到场次 `publish/cover_history/<序号>/<版本ID>.jpg` 与 `<版本ID>.raw.jpg`，提示词、补充要求、版本编号记录在发布包 `cover_history`。不自动删除旧版本；服务器备份应包含这些文件。新功能上线时，当前仍在磁盘的旧 Seedream 成品会在下一次成功生图时纳入历史；以前已经覆盖且没有备份的图片无法补回。

生成失败时保留原封面；程序化封面与 Seedream 历史可继续选择。模型可能无法完全满足所有视觉要求，生成后仍需核对人物辨识度、构图和封面文案。

CLI 示例：

```bash
# 只预览，不调用模型
.venv/bin/python scripts/publish_pack.py output/<场次>/candidates.json --rank 1 --cover-prompt-only --cover-supplement='人物靠右，背景粉紫'
# 基于直播画面生成，封面字由程序叠加
.venv/bin/python scripts/publish_pack.py output/<场次>/candidates.json --rank 1 --cover-mode seedream --cover-reference frame --cover-supplement='背景简洁，增加漫画猫爪' --cover-text='这也行？'
# 选择发布包中已存在的版本 ID，不调用模型
.venv/bin/python scripts/publish_pack.py output/<场次>/candidates.json --rank 1 --cover-select-version <版本ID>
```

部署需同步前端构建、后台接口和 worker Python 文件；只替换其中一部分可能缺少输入框或参数接口。
