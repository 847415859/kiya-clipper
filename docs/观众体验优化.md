# 观众体验检查

成片编辑页右侧提供“观众体验检查”，优先帮助第一次认识主播的观众理解起因、原话和反应。

## 编辑与复看

- 根据现有精排结果提醒：前情依赖、结构不完整、关键原话识别存疑、开头偏弱。
- 精排建议了前情时，检查全文是否从成片开头一秒内开始显示，并有足够的可见时间。可点“补到开头”添加，再人工修改、保存；不自动替换人工内容。
- “标题、封面与内容对照”展示当前发布包、AI 事件描述、笑点原话和证据。证据位置由原始候选时间换算到素材范围，不使用精排后的新起点；超出素材范围的证据不能定位。
- 对底部装饰、小字号、背景音乐未压低做规则提醒。底部位置提醒不是实际遮挡检测，是否挡脸、挡字幕仍需观看。
- 渲染后点“手机成片复看”：390px 宽度、静音开关、前 3 秒播放及完整播放。使用真实渲染文件；改变预览宽度不改变视频画幅。未保存、已保存但未重新渲染的改动都不会出现在旧成片里。
- 最近一次质检展示对应成片路径和报告时间，不能视为当前修改已通过验收。

## 自动生成与渲染

- 必要前情会在密度限制、鼓点吸附、梗过滤和总数裁剪后再次检查，优先保留，为其让出装饰效果位置。不覆盖人工保存的终稿。
- 聊天伪 UI 在编辑预览和成片中统一显示“剪辑演绎”，避免把剪辑添加的内容当成真实弹幕。
- 成片质检读取渲染 props 中的真实字幕事件，提醒空字幕、每秒超过 10 个非标点字符或至少 4 个字却不足 0.7 秒的字幕；提供时间和文字样例。
- 根据渲染画幅与 1080p 基准字号，估计 390px 宽度下的字幕字号，小于 12px 提醒复看。这些数值是初始启发式阈值，不是平台规定，不阻止保存或发布。
- `edit_v7` 增加观众理解、前情与反应保留、真实引用等要求，保留为可选实验版本。默认仍为 `edit_v6`，等待真实片段和人工审核对照评测。

## 验证与边界

- Python 回归覆盖前情裁剪、重复补充、数量和密度限制、短片范围，以及字幕可读性。
- 前端规则测试覆盖证据坐标、裁剪外效果、前情补充和聊天演绎标识。
- 修复 Windows 下字幕滤镜路径的两层转义，以及自定义渲染命令对反斜线和带空格路径的处理；使用实际 FFmpeg 验证字幕烧录，Remotion 在流程测试中使用假渲染器。
- 浏览器使用模拟接口和测试视频验证前情保存、证据跳转、按修改时间选最近成片、静音切换、前三秒暂停、完整重播，以及窄屏弹窗；没有代替真实场次的内容验收。
- 标题事实准确性、陌生观众理解程度、人物遮挡与实际混音效果仍需人工复看；本次没有新增模型评审调用。
- 线上使用需要更新 worker、renderer 和后端，并重新构建 admin。已存在的成片需要重新渲染才会获得新的演绎标识和字幕质检；旧质检不会自动补算。
