# 参考视频剪辑蒸馏技术方案 v2

## 1. 目标与阶段边界

在一次可续跑的研究批次内，从最近 500 天的参考作品中提炼**有条件、可解释、能回到原片验证的剪辑判断**。系统要能根据证据判断从哪里进入、哪些信息必须保留、在哪里收束，以及何时建议跳过或保留原边界。

蒸馏和验收只使用参考库。蒸馏数据通过参考库内的独立验证后定版。kiya 原素材、账号偏好与制作素材在后续融合阶段进入。融合以 kiya 的实际内容生成候选片段，参考库提供剪辑判断及适用边界。

本版整合了[多账号风格蒸馏执行方案](多账号15分钟内成片风格蒸馏执行方案.md)、[切片系统优化实施方案](基于参考风格分析的切片系统优化实施方案.md)、[参考视频续跑指令](参考视频蒸馏续跑指令.md)及现有研究产物。沿用事件节点、声画证据、同一事件的上下文约束、可追溯时间轴和续跑账本。本版以 500 天参考范围和参考库独立验收界定工作范围。

## 3. 一批完成的执行流程

| 顺序 | 执行动作 | 阶段产物 |
| --- | --- | --- |
| 1. 冻结清单 | 确定 500 天窗口、资格、版本、提炼与留样分配。盘点可复用证据，按案例缺口列出需要新增的工作 | 批次清单、复用清单、缺口及费用预估 |
| 2. 梳理全片 | 对入选作品用现有转写、概览和已有观察定位开头、中段、结尾、事件及依赖。标记需要深看的短窗 | 全片内容骨架、事件范围和语义缺口 |
| 3. 连续声画深拆 | 从最短可解释前情看到有效回应结束。原声与连续画面覆盖同一事件范围，必要时前后扩看。抽帧用于定位和复核证据 | 原片回看窗、事件节点、声画字幕时间线、剪辑判断 |
| 4. 单变量对照 | 从参考库建立同源 A/B。每组只改一项剪辑动作，先独立看各版、记录理解，再比节奏与取舍 | 对照预览、标签、观察依据和反例 |
| 5. 独立复核 | 复核先看原片和问题，独立记录触发者、回应者、事件边界，再与首遍结论比对。只对会改变结论的分歧加密取证或重听 | 复核记录、时间和模态校验、待复核区间 |
| 6. 冻结规则并验收 | 先冻结规则版本，再打开留样。逐条判定适用、不适用或证据不足。规则修订后，在此前未阅的预留样本上验证 | 冻结规则表、留样结果、验收报告和数据包 |

建议从已有 28 条中优先复用质量足够的配对，首批规划 **8–12 组 A/B** 作为起点。优先补会改变剪辑决定的正例、反例和证据不足案例。新增分析量随缺口、重复程度和预算调整。每个视频的阶段状态与证据路径落盘，恢复时从缺口继续。

## 4. 优先蒸馏的决定

| 判断 | 对照只改什么 | 优先检查 |
| --- | --- | --- |
| 必要前情 | 从精彩点进入，或多留一条最短的可核验触发 | 初次观看能否识别反应对象和原因 |
| 完整回应 | 在首个反应处结束，或等最后一个有效回应、结果卡或声尾结束 | 最后补上的信息是否改变理解，原话和回应人是否保住 |
| 换题分段 | 在首段闭合处结束，或接入后续互动 | 观众是否会误认后段属于前一事件 |
| 画面线索 | 保持原画面，或突出已有真实弹幕、物件、界面 | 能否解释反应，是否干扰阅读或遮挡人物 |
| 节奏与删减 | 保留一处明确的重复或等待，或试做局部缩短 | 视觉、字幕、动作和原声有没有信息损失，过渡是否自然 |

前两项优先完成。每类至少策划适用、应跳过、证据不足三种案例。画面静止、低音量、无转写只作为定位信号。自然等待尚无通过复核的压缩正例，先保持为复核提示。旧载入试剪移除 **84.75–85.25 秒**，与约 **85.04 秒**开始的短声候选重叠，可用于检验误删风险。 [试剪与复核](../worker/output/_reference_study/distillation/reference_batch_v1/natural_pause_review/review.json)

具备同源原素材时，可核对参考成片实际删留和重排；原素材仅用于已匹配参考成片的证据复核。只有成片时，局部改剪以实验版本登记，源素材删留与作者意图标为未知。A/B 固定其余边界、字幕样式、音量及效果。结果可以是 A、B、两者均可、两者均不可或证据不足。记录复核主体是模型、剪辑师还是真实观众，独立看片后的理解记录与主观偏好分开保存。

## 5. 模型分工与时间证据

| 环节 | 本版技术选型 |
| --- | --- |
| 全片梳理与新视觉证据 | 复用现有转写、抽帧概览和事件索引。新增视觉分析首选 `qwen3.8-flash`，`qwen3-vl-plus` 的旧结果用于复用和校准对照。证据足够的旧段无需重跑 |
| 关键连续声画 | 优先验证 `qwen3.8-omni-flash`，给它同一原片窗口的连续视频与原声。先实测接口能否读取负载中的音轨或组合输入。联合输入受限时，按同一源窗口分别解析画面和音轨，再对齐证据 |
| 原话和句词边界 | 复用本地 ASR。关键短窗有争议时，对照 `qwen-audio-3.1-asr-flash-filetrans` 的句词时间戳。说话人、笑声、声尾和音效的关键归属回到原音核对 |
| 规则综合与难例复核 | `qwen3.8-flash` 首选输出严格 JSON Schema。只有错接事件、声画证据冲突等分歧会改变结论时，才用 `qwen4-max` 复核整理好的证据 |

恢复后先用已经渲染的参考 A/B 校准案例验模型和端点，留样仍保留到规则冻结后。检查事件顺序、关键回应、模态归属和证据引用，再按**每条通过验收的记录成本**选定主力。常规模板化任务可试更便宜的 `qwen3.7-flash`，只有同输入检查表明质量足够才批量使用。截至 2026-11-23 查阅的百炼北京公开单价，`qwen3.8-flash` 与非实时 `qwen3.8-omni-flash` 的输入和输出均分别为 0.8 元和 2.7 元每百万 Token，`qwen4-max` 为 10 元和 30 元。不同模态耗用的 Token 数和实际账号计费以用量记录及账单为准。 [百炼价格](https://help.aliyun.com/zh/model-studio/model-pricing) · [Omni 模型能力](https://help.aliyun.com/zh/model-studio/qwen3-8-omni-flash) · [文本与视觉模型](https://help.aliyun.com/zh/model-studio/text-generation-model)

模型优先返回证据 ID，例如句子 `S42`、画面 `F18`，以及它们在事件中的角色。统一时间轴由可信索引解析。分别保留原片解码 PTS 与 time base、原成片播放区间、片段局部时间及偏移、ASR 时标、试剪输出时间。只在一个位置执行偏移换算，并校验区间越界、秒与毫秒混用、重复叠加和跨窗重叠。发现异常保留原值、推导值与依据。内容有分歧时标记观察、解释或冲突。结构通过后继续检查证据有效性。

下列文件是拟交付的数据规格，沿用原产物路径及标识引用历史证据。批次目录保存清单、校验结果与续跑入口。

| 文件 | 必填内容 |
| --- | --- |
| `manifest.json` | 批次日期及窗口、参考账号和作品、证据版本、原始场次或事件分组、资格、留样分配、阶段状态、既有产物引用 |
| `events.jsonl` | 作品和事件 ID、事实与解释、前因/触发/变化/回应/收束、前后依赖、必保节点、建议边界、字幕和声音状态、证据 ID、缺口 |
| `evidence_index.jsonl` | 证据 ID、媒体或历史产物路径及版本、坐标类型、原片区间或锚点、回看片、转写来源与验证方式 |
| `comparisons.jsonl` | 同源 A/B、唯一变量、控制项、预览或编辑区间、独立理解记录、偏好、误用与回退 |
| `rules.json` | 规则 ID 与版本、目标、触发条件、动作、跳过条件、回退、正反例、留样结果与使用状态 |

规则状态用**可给建议、只提示复核、待补证**。有足够的独立案例支持条件，而且留样能验证边界，才可给建议。涉及精确剪点或声尾时，单独校验原片证据。对现有机器辅助数据延续原有验收标记。

## 7. 验收、预算与续跑

- **证据验收。** 每个交付为已深拆的事件都有完整叙事窗口、原片可回看的引用和明确的判断状态。报告按视频区分已索引、已深拆、已独立复核以及已参加留样。候选边界允许以可复核范围交付，证据不足的精确边界单独登记。
- **决策验收。** 核对有没有漏必要前情、截断回应、错接另一互动、误认说话人及引用错误时间。遇到此类错误，缩窄具体规则或降低其状态。其他具有独立证据的规则继续完成验收。对照结果记录使用和跳过的代价，保留分母与未解决数量。
- **预算。** 沿用最近一次执行口径的 **250 元累计总上限**，全片分析池 **170 元**，精拆与复核池 **80 元**。旧账本两笔记录的账面合计为 **6.321191 元**，实际账单尚未核对；近两轮本地研究新增模型费用 0 元。外部调用前按适用账单口径核对历史估算、未知预留、在途预留及下次请求的保守估价。复用另记，失败也保留用量。 [成本账本](../worker/output/_reference_study/distillation/reference_batch_v1/cost_ledger.json)
- **自行执行。** 样本选择、原片复核、额度内定向补采、案例重标和验收可按批完成。优先复用已有证据，再回本地原片，最后才考虑云端短窗。重复出现同类结构或时间错误时，暂停受影响的外部路径，离线定位后以最小样本验证。仅在预算触顶仍需追加、关键证据无替代方案或涉及生产变更和发布时汇总决策项。

本批结束以**冻结的规则、参考库留样结果和可回看的证据包**为准。标记研究资质与生产批准状态供交接。 [现有续跑入口](../worker/output/_reference_study/handoff/NEXT_BATCH.json)

## 8. 定版后的 kiya 融合

融合阶段接收冻结规则版本、适用条件、证据要求及回退动作。用 kiya 的原素材建立她自己的事件与证据索引，由她的原话、画面、内容偏好和互动关系决定选段和编排。输出候选起止、前因、转折、应保留的回应、适用规则以及待核对的位置；证据不足时，可建议扩大素材范围或暂不给候选。

先用同一批未参与融合调校的 kiya 素材，固定模型和输入，对照现有流程与加入规则的流程。验收关注首次观看能否看懂、关键回应是否保住、是否错接互动、证据能否点回原片，以及重复运行是否识别同一事件并保住相同信息。需要测模型升级时，固定已验收规则，再单独换模型对照。阶段产物为可在编辑器查看和修改的候选片段及其证据。
