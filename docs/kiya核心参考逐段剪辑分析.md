## 2. 需要修正上一轮的粗概括

1. A 不宜仅归为“柔和、少特效”。它的粉白视觉比较柔和，但开场、加载、重复强调、领奖台和弹幕切换并不少。更准确的名称是 **互动考题—反应递进**。
2. B 的重点不只是“热闹”。它把同一个悬念逐步解释清楚。更准确的名称是 **误导设题—观众接话—真实揭示—澄清收束**。
3. X2 / X3 表示编辑在强化重复，不能单凭这个图形就断言同一原片段被回放。它们也不自动代表两次独立推镜。
4. 画面变化、场景检测峰值、原视频剪切、后期效果切换，是不同的统计对象。
5. 显示弹幕和等待观众读完也是信息，不能把没有识别出语音的时段等同于废片。
6. 增加效果预算不能补上“不会切真实弹幕、不会安排揭示、没有独立音效轨”等能力。

## 3. A：互动考题—反应递进

### 3.1 观众实际在追什么

从画面字幕可观察到：观众对人物的辨认或知识回答提出挑战，人物回答、迟疑、修正，随后又解释或找补。观众的关注由“她会怎么答”转向“她会不会承认”。因此后半段的反馈不是可任意裁掉的尾巴。

其结构可写为：

`开场突出题目/反应 → 一轮找补 → 新问题 → 自信回答 → 错误与修正 → 迟疑 → 再确认 → 找补 → 弹幕回击 → 评论性结论 → 回人物 → 片尾`

这是一组同主题的多轮互动，不适合用“找一个笑点，前后各留几秒”描述。没有源录播，不能确定开场是预告重排、源时间顺排还是另取片段；先将它记录为成片开场组织。

### 3.3 A 中最值得学习的三个选择

- **先给题，再看答。** 38.6–39.6 秒突出 tomato / potato 弹幕后，才回到人物的自信与回答。若只从口误处开剪，新观众失去比较基准。
- **保留有目的的迟疑。** 52–60 秒左右的加载画面把思考变成一个可看的阶段；不能据此建立“每次停顿都留八秒”的规则，也不能按纯静音阈值全部删除。
- **把找补当成内容。** 69 秒之后的解释、弹幕反击和“年度嘴硬王”构成另一层反差。结束点应问“人物与观众的互动是否收束”，而非只问“错误答案说完没有”。

**字幕尤其要区分两种错误：**ASR 听错需要校正，人物本来就说错的答案应忠实保留。若模型把口误字幕自动改成正确答案，就会直接抹掉这一条的内容价值。纠正信息只能作为明确的编辑注释或后续原话呈现。

## 4. B：误导设题—观众接话—真实揭示

### 4.1 事件的价值不是某一句暧昧表达

字幕和画面围绕“工作、分析、视频、诱导、交换、黄色的东西”等表达连续推进，观众接话，再出现电池相关对象和更明确的解释，最后由人物回应收束。

结构是：

`悬念引入 → 具体铺垫 → 观众插话 → 回应/装傻 → 找对象 → 视觉揭示 → 再接话 → 原话解释电池 → 澄清 → 短反应插入 → 片尾`

因此，前 30–40 秒可以很有悬念，却不足以代表完整事件。选段要寻找揭示和回应，不能仅凭刺激程度选前半段。本轮未据此判断系统某一条实际候选已犯同样错误，因为还没有该候选与原录播对照。

### 4.3 B 中最值得学习的四个选择

- **铺垫也在剪。** 5.8 秒后从冲击线切为暗角和指示手势；分析、思考、金币元素分别跟随语义。它们不是只在最后的笑点处出现。
- **把观众变成可见的对话参与者。** 30.2、43.2、62.6、85.2 秒附近的弹幕取景承担不同接话功能，不能合并成一个笼统的“高能弹幕花字”。
- **揭示分两层。** 60.8 秒附近先让观众看到相关界面对象；78 秒附近原话进一步落到换电池。视觉指向与语言解释互相补足，不能只看其中一层就宣布事件完整。
- **高潮后给澄清。** 81–90 秒左右的原话与观众反馈，是对前面误导的收束。然后才接约 1.4 秒全屏反应与约 3.1 秒 CTA。

## 5. 节奏、重复与声音：能证实到哪一步

### 5.1 阅读时间与话语空隙

- A：转写约 12.0–13.9 秒未给出连续语句，但画面仍在突出弹幕。这里存在阅读信息，不能自动归为待删静音。
- A：52–60 秒左右有加载图形与人物反应；不把这八秒都认定为无声，也不假设它们在源录播中原本相邻。
- B：约 41.5–42.1 秒，机器语句间有空隙，同时混音在 41.4–42.2 秒低于本次 -40 dBFS 阈值。它处于强调后再回应的阶段；是否删短仍需听音和样片比较。
- B：60.8–62.6 秒的对象揭示即使台词少，也有明确的视觉任务。基于 ASR 字数或能量强弱删片都会漏掉这个任务。

### 5.2 对 X2 / X3 的核验

A 的 64–69 秒存在近景、重复字幕和 X2 / X3，这些画面事实已核对。额外将混音 60.4–62.2 秒与 63.8–69.0 秒内等长滑窗做归一化相关比较，最高值约 **0.141**。

这一次检查不支持把两段当成原样复制的同一混音片段；但原声、BGM、音量、变速或特效可能改变相关性，因此它也不能证明绝无回放。结论保持为：**已确认重复强调，源回放关系未知。** 数据不是让模型凭 X2 标签生成假的回放依据。

## 6. 为什么当前系统容易剪得不像

这是代码层核对，不代表已经对当前某条失败成片做了定位。

| 差距 | 当前行为 | 参考片给出的反例 / 影响 |
| --- | --- | --- |
| 核心表达与事件收束混为一谈 | 精排交接有单一 punch、setup、reaction；还需核对完整互动节点是否真正进入生产边界选择 | B 的悬念和揭示相距较远；A 的找补与观众反馈会产生第二层反差 |
| 自动初稿的片中删减能力不足 | `autoedit.py` 的 `EditOut` 为 trim/items/note，渲染虽支持 cuts，初稿没有系统地产生有证据的 cuts | 无法把长等待、重复表达和有效停顿做细粒度区别 |
| 取景对象过于单一 | `edit_v6` 明确要求放大对准主播的脸 | 参考会在人物、弹幕、界面对象之间交接注意力 |
| 铺垫阶段一律克制 | `edit_v6` 要求贴图只放反应节拍、铺垫不放 | B 的分析、思考与交换段已经使用语义图形；这不是最后一个笑点后的贴图 |
| 强调被当作互不相干的 Zoom | 两次 zoom 开始间隔小于 10 秒会在 `enforce_density` 被丢弃 | 参考有连续的取景与强调状态；用多个 zoom 近似时可能被规则过滤，但 X2/X3 本身不证明是两次独立 zoom |
| 数量预算按时间先后截断 | 默认 max_items=8；超过上限后按排序保留前面的 items | 前段包装可能耗尽预算，后段揭示或收尾没有优先权。应按叙事价值取舍，不是只把 8 调大 |
| 贴图去重过于机械 | 同一素材整条一次、最多两张的限制 | B 的同类指示手势在后段再次回扣；是否同一素材文件未知，但同一视觉词汇允许有理由地重复 |
| 真实弹幕与伪 UI 混用风险 | 当前有 fakeui/chat，却没有独立真实弹幕证据卡类型 | 样片的真实观众输入不能通过自编伪聊天替代 |
| 缺少独立画面处理状态 | 主类型是 text/zoom/sticker/narration/fakeui | 暗角、背景虚化、全屏插入、局部内容卡和纯取景切换不是同一个贴图类型 |
| 缺少独立效果音编排 | 主渲染层有源视频音频、可选 BGM 与前情视频，未见独立的 SFX cue 序列 | 无法仅通过让模型写“配一个音效”保证实际成片有相应声音；具体参考声音仍需听音确认 |
| 编辑初稿对音画的观察不足 | 精排抽少量图，自动初稿主要读取文字交接和逐字稿 | 说话节奏、微表情、真实弹幕位置和视觉揭示可能没有进入决策输入 |

代码入口：`prompts/edit_v6.md`、`worker/scripts/autoedit.py`、`worker/clipper/edit.py`、`worker/clipper/timeline.py`、`renderer/src/Clip.jsx`。

## 7. 应当提炼成什么制作规则

### 7.1 先明确“观众此刻知道什么”

每个事件至少标注：触发问题、回答对象、首次表达、必要转折、揭示/纠正、后续反应、收束依据。不是强迫每条都有全部节点，而是说明缺哪些节点会影响理解。

剪辑动作必须回答一个具体问题：

- 放大弹幕：让观众读清谁问了什么。
- 回人物：让观众看谁在回答及如何反应。
- 语义图形：把这一句中的某个含义视觉化。
- 留停顿：等人物反应或等观众读完信息。
- 近景与评论字：强化已经有证据的态度或转折。
- 全屏反应：对已经成立的事件补一个评论性结论。

没有回答这些问题的动作，可以不加。

### 7.2 分开三条时间轴

1. **源素材时间轴**：所有取用区间的真实源文件与入出点。
2. **成片叙事时间轴**：哪些片段依次呈现，是否重排、重复或插入。
3. **包装与声音时间轴**：字幕、取景、处理、贴图、音效和 BGM 如何落在成片上。

当前 cuts 删除后压缩时间可以复用，但不能自动覆盖任意重排、同源回放或外部反应插入。应显式建立 source→finished 映射，不能把参考成片时间直接当成新素材时间。

### 7.3 让风格与强度分开

- 风格维度：互动考题—反应递进 / 误导—揭示 / 自然表达等。
- 强度维度：克制、标准、热闹仍可保留，但每一档都要遵守事件结构与内容触发。
- 资源维度：有哪些可用贴图、声音和全屏插入素材。缺少资源时应降级或省略，不生成一个不存在的文件名。
- 品牌维度：字幕字体配色、头像和 CTA。A、B 的 CTA 都约 3.1 秒；这与网站另外提供的日程片尾属于不同模块，不能混作同一种主体节奏。

### 7.4 预算按作用分配，不按最早出现分配

先保留必要提问、揭示、反应，再分配可选装饰。将持续背景处理与一次语义强调分层；不能把常驻暗角与一个问号都简单记成同等的“效果数量”。对被校验器删除的建议记录原因，便于知道是模型没设计还是程序过滤掉了。

## 8. 下一条对照样片应怎样验收

拿同一段原录播，生成纯净剪辑与适用参考风格的版本。不能用这些已经包装的参考成片再叠一层效果来冒充复现。

| 维度 | 验收方法 |
| --- | --- |
| 选段 | 新观众能指出问题、回答对象、关键变化与结束依据；必要揭示不缺失 |
| 原话 | 原有口误保留，ASR 错误校正；不增加主播未说过的话 |
| 节奏 | 每个保留停顿或删除区间有理由；人名、半句话、笑声或尾音没有被无意切断 |
| 取景 | 弹幕可读、人物可见，对象卡来自真实证据；阅读完成后恢复主体 |
| 包装 | 每个强调能定位到内容触发；预期的揭示和收束没有被前段预算挤掉 |
| 声音 | 实际听音比较原声、效果音与 BGM 的可辨性；未核实的声音不算复现成功 |
| 时间轴 | 删除、回放或插入后，字幕、镜头和音频仍与对应内容对齐 |
| 风格 | 用户盲选更接近参考的版本，并具体记录采纳/删除哪些动作 |

**本报告完成后仍缺：参考对应原录播的源时间映射、完整听音标注、当前失败样片对照、实际渲染验证。** 这次已把观察细化到可讨论的编辑状态和具体代码差距；它还不是已经验证过的自动制作能力。
