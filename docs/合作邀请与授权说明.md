## 三、书面授权确认要点

私信里确认也可以，最好让对方用一句话明确回复，截图存档。正式一点可以做成一页确认书，写清：

1. 双方身份：主播名称、B站 UID 646830928；你的切片号名称和 UID。
2. 授权内容：上表中勾选的项目。
3. 发布范围：哪些平台、哪个账号；是否允许商业变现（建议先写“不商用”）。
4. 署名方式：标注“非官方切片”，附主播空间和直播间链接。
5. 期限与撤回：有效期（例如一年，到期可续），主播可随时撤回，撤回后多久内删除。
6. 内容边界：禁止切的话题；主播要求删除时的处理时限。
7. 日期和双方确认（截图或签名）。
